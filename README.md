# bubble-rumble-site

Bubble Rumble 소개 페이지와 개인정보처리방침.
`https://kakimind.github.io/bubble-rumble-site/`에 GitHub Pages로 배포된다.

- `index.html` — 랜딩 (KAKIMIND Issue No. 01 매거진 에디토리얼 시스템, §08, 스팟 컬러 `#2f7cf6`)
- `privacy.html` — 개인정보처리방침 (앱 고유 디자인)
- `assets/` — 캐릭터 아트. 원본은 앱 저장소의 `assets/images/skins/`.

앱 소스 저장소는 따로 있다 (Flutter, `com.kakimind.bubble_rumble`).
